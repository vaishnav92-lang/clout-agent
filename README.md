# Clout Agent (member kit)
Your network, mapped by your own agent, on your own machine.
- Built from data you already own: LinkedIn export, your mail, your messages.
- Nothing leaves without an approval card showing the exact payload.
- Every access is appended to a local ledger.
Install (requires Claude Code + a Claude subscription) — one command, no npm account needed:

    npx github:vaishnav92-lang/clout-agent

(or: curl -fsSL https://raw.githubusercontent.com/vaishnav92-lang/clout-agent/main/install.sh | sh)
Then: cd ~/clout && claude → "set up clout"
Privacy model: docs/data-posture.md

# Data posture
- Your graph lives in ~/clout on your machine. We run no server that sees it.
- Inference runs on YOUR Claude account (Anthropic), under your terms with them.
- Asks arrive as text; responses default to counts-only; contact info has no
  schema field and cannot be sent; referrals require the person's own opt-in reply.
- The ledger (~/clout/ledger/) records every access and every payload sent.
- The code is public — read what it does.
